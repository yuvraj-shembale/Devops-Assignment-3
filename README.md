Provisioning an AWS EC2 instance using Terraform, following the standard IaC workflow of init, validate, plan, apply, and destroy.

## Workflow Commands
1. \	erraform init\ - Initialize working directory and download provider plugins
2. \	erraform validate\ - Validate configuration syntax
3. \	erraform plan\ - Inspect execution plan
4. \	erraform apply\ - Provision EC2 instance
5. \	erraform destroy\ - Teardown and clean up resources
